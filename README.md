A tiny Node program that writes the world's most useless superpower — one line, 140 characters max — to `/output/entry.txt`, for make.fun's "Worst Superpower" bounty.
The power itself is gloriously pointless: a single raindrop, summoned indoors, landing on its owner's own head, once a day — and nothing else.
No clouds, no storms, no heroics: just one damp forehead, on schedule.

## Run it

```sh
node main.ts
```
